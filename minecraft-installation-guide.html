Guide on How to play Minecraft in Our Server!

Follow this guide to set up your device for a multiplayer minecraft game.


Step 1, install a Minecraft launcher, here we will use sklauncher. Go to the sklauncher downloader website, then follow the install instructions. Don't worry about installing a Java version, sklauncer installer takes care of it.


Step 2, either log in with Microsoft if you have bought a Minecraft account before, OR you can also play offline if you don't have a Minecraft account before. In case of offline mode, put your username however you wish.


Step 3, once you're logged in, either online or offline, create a new installation by pressing this plus button next to "Installations Manager".


Step 4, double check which version of Minecraft we use and use it here. At the time this guide is written, we use Fabric 1.20.1 for our modpacks. Tick "Use separate instance folder" if you plan to play with other minecraft installations. As for the name, use any name you wish.


Step 5, open the extra menu button on the newly created installation, then choose "Open installation directory". This will open up a folder.


Step 6, if you haven't played this installation before, this folder will be empty. If so, create a folder named mods, plural, then enter it. If you have played it, just open the mods folder.


Step 7, put the modpack (all the .jar files) inside that mods folder. You may close this folder after you're done.


Step 8, go back to your sklauncher windows, then press play.


Step 9, go to multiplayer, then add server.


Step 10, put in what name would you use to store our server (this one is up to you), then put in the url of the server. Currently we're using technologies-aspect.gl.joinmc.link but please double check with the server owner!


Step 11, now you can play along with us when we're online! Keep in mind that our server is on only when we're turning it on, so please ask us or join us while we're online.
